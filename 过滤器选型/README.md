# 过滤器选型子模块

## 职责

本模块只根据以下输入生成标准过滤器规格和数量：

- 过滤器安装形式：抽拉过滤或框架过滤；
- 过滤器类型；
- 箱体宽度模数；
- 箱体高度模数。

过滤段长、检修段长和检修门不属于本模块职责。

## 文件边界

| 文件 | 职责 |
|---|---|
| `index.html` | 页面结构与语义 |
| `css/filter-selector.css` | 页面样式 |
| `data/filter-database.js` | 过滤器类型和 6–33M 标准排布数据 |
| `js/filter-selector.js` | 选型计算和结果渲染 |

根目录的 `过滤器选型.html` 是兼容入口，不放置业务数据或计算逻辑。

## 规格编码

规格编码由宽、高方向的单个排布值拼接而成。例如宽度值 `5`、高度值 `4` 对应规格 `54`。同一规格会合并统计数量。

## 维护规则

1. 标准排布变化只修改 `data/filter-database.js`。
2. 计算与展示变化只修改 `js/filter-selector.js` 或 CSS/HTML。
3. 数据库不得加入过滤段长或检修门字段。
4. 修改后必须验证两种安装形式的全部 6–33M 宽高组合。
