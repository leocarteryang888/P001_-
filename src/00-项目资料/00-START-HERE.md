# P001 无框架箱体产品方案设计软件

## 项目定位

本项目依据 `QHB-J02.577-2026A` 规范和《组合式空调机组选型软件技术规格书 V1.5》开发模块化 AHU 选型工具。过滤器、盘管和整机工作台物理隔离，各自维护页面、数据、逻辑和测试，通过统一项目数据接口协作。

## 接续顺序

1. 修改任何文件前，完整读取 `01-项目架构与维护规则.md`。
2. 涉及总体业务流程、字段归属、跨模块接口或验收口径时，先读取 `组合式空调机组选型软件技术规格书_V1.md`；该文件为当前权威规格。
3. `AHU_选型软件_现有界面改造需求说明_Codex.md` 作为界面改造的原始需求依据保留；出现表述差异时，以当前技术规格书为准，并在规格书中维护来源追踪。
4. 只进入本轮任务涉及的一个业务模块，不顺带修改其他模块。
5. 需要核对产品规范时，从项目根目录的 `references/箱体设计规范/` 读取，只把已确认的规则写入业务源码。
6. 完成修改后，运行目标模块测试；涉及目录、公共工具或项目规则时，运行全部测试和结构校验。
7. 页面源码以 `src/<模块>/index.html` 为入口，导出文件和临时验证产物不得写回源码目录。

## 目录入口

| 目录 | 用途 |

| `src/00-项目资料/` | 项目入口、架构与维护规则 |

| `tools/` | 本地开发服务器、启动和项目校验工具 |
| `.agents/skills/p001-selection-software/` | 本项目后续维护使用的项目级 skill |
