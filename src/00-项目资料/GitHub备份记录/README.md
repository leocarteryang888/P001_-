# GitHub 备份记录

本目录记录源码、项目规则、开发计划和模块维护资料上传到 GitHub 的时间节点，便于选择恢复点。

## 使用规则

- 只有发生实际修改时才建立备份记录。
- 重要修改开始前，先记录当前稳定提交作为恢复基线。
- 每个工作块完成并验证后上传一次，并登记提交号和内容概述。
- 用户确认模块验收后，登记稳定版本标记。
- 本目录只记录 GitHub 提交信息；客户项目运行数据、私有零件库数据和临时文件按本机独立备份规则保存。

## 恢复方法

恢复前先确认目标提交号和需要恢复的文件范围。优先在独立分支或副本中恢复，核对启动入口、项目数据和模块状态后，再决定是否替换当前工作版本。
