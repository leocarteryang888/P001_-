# 盘管选型子模块

入口：`src/02-盘管选型/index.html`。与过滤器模块独立，不互相引用代码或数据；整机工作台只传递统一项目条件并打开本专业模块。

## 输入与输出

- 输入：箱体规格（HHWW，前两位为高模数、后两位为宽模数）、排数、换热管直径、汇管直径。
- 为准确选取数据，另需选择安装形式（吊顶/落地）；本版标准表仅适用于 25W 箱体。
- 输出：STTL 参考规格型号、单件迎面宽高、数量、厚度、查表依据和复核提示。
- 程序严格匹配原表规定的换热管径，不会悄悄改变用户输入，也不会为非标准箱体外推型号。

## WK 无框架式盘管有效迎风截面候选

- `data/coil-section-database.js` 是从用户提供的 `22.xlsx` 只读派生的默认几何库：读取“机组型号参数表”B列为“WK-无框架式”的434条记录（φ9.52 135条、φ12.7 299条，其中源表标记推荐72条），只保留宽/高模数、源推荐标记、管径、盘管有效长度和H/I/J孔数；不包含KS/KU记录，也不复制或覆盖原工作簿。
- 管距从同一工作簿“盘管结构参数表”读取：φ9.52为25mm，φ12.7为31.75mm。有效迎风面积 = 有效长度(mm) × 孔数总和 × 管距(mm) ÷ 1,000,000；候选迎面风速 = 送风量(m³/h) ÷ 3600 ÷ 有效面积(m²)。
- `js/coil-selector.js` 提供纯函数列出全部风速区间内候选。工作台默认1.5–3.0m/s，边界包含；这是可编辑的候选过滤条件，不是规范限值或工程判定。候选按风速升序显示；源“是否推荐”只作为数据标记，模块不自动选定候选。
- 工作台必须由工程师选中一行并显式确认截面，确认后实际箱体宽、高写回机组设计条件并沿既有项目CAS保存与专业结果失效流程处理。后续送风量改变时重新显示候选和已选截面风速；越出当前筛选范围仅警示、不静默换截面。
- 手工非标截面只按实际名义宽×高换算“名义截面风速示值”，不冒称盘管有效迎风速度，不产生表冷器型号或性能结论。盘管制冷量、风阻、水流量和水阻仍须专业软件复核。
- 基准核对：源表第106行（11×15、φ9.52、有效长度875mm、孔数54、管距25mm）在10000m³/h时迎面风速约2.35156m/s；第241行（11×15、φ12.7、有效长度875mm、孔数42、管距31.75mm）。在10000m³/h及1.5–3.0m/s区间中，434条WK数据返回112条候选（φ9.52 52条、φ12.7 60条）。

## 数据来源与边界

原始规范 QHB-J02.577-2026A：

- §2.5.11 表2.5-5、表2.5-6：吊顶与落地各151条，保存每条记录的管径、数量、高度及六种汇管径对应宽度。
- §2.5.6 表2.5-2：排数2/3/4/6/8，φ9.52/φ12.7，DN32–80厚度；DN100未列，显示“资料未提供”。
- §2.5.12 示例表明型号尺寸字段使用 A/100、B/100，多层后缀 H 加数量；本界面保留必要小数，不擅自对表列尺寸取整。
- §2.5.5引用的完整物料编码细则 QHB-J02.004-2012 未提供，因此输出明确标为参考规格型号。
- 规范正文B≤1450mm与部分标准表的1524/1460.5mm冲突；保留原始表列数据，显示待复核，不生成型号。
- 非标计算参数表与例题中K/S等取值存在不一致，本版不实现非标公式，也不套用到50W箱体。
- 不能用这些几何输入核定制冷量、管程、水流量或压降；按§2.5.2另用盘管性能软件计算。

## 文件职责

- data/coil-database.js：逐行标准数据库及厚度表，数据更新只改这里。
- data/coil-section-database.js：源表派生的WK有效迎风几何候选，只作为截面几何，不等同盘管型号/性能结果。
- js/coil-selector.js：盘管标准选型与迎风截面候选纯计算逻辑，不包含页面操作。
- js/app.js：表单与展示。
- css/coil-selector.css：独立样式。
- tests/coil-selector.test.js：全量组合、源数据对照和模拟页面交互。

## 数据库维护

页面右上角“数据库维护 · Excel”支持：

- 在线查看当前生效的吊顶标准表、落地标准表和厚度表，不下载文件；
- 将当前生效数据导出为 XLSX；
- 导入 XLSX/XLS，完整校验三张表后由用户点击“应用导入”；
- 浏览器覆盖数据保存在当前页面地址的 localStorage，不改写磁盘默认数据库；导出文件应作为备份；
- 禁止公式、重复规格、缺失尺寸、非法管径和不完整厚度表；校验或保存失败不替换当前数据。

Excel 功能使用子模块内 vendor/xlsx.full.min.js（SheetJS CE 0.20.3），不依赖过滤器模块或运行时网络。

## 热更新

- 直接打开 `index.html` 属于 `file://` 文件模式，适合离线使用，但浏览器不会自动刷新。
- 开发时双击 `tools/启动盘管选型-热更新.bat`，页面通过 `http://127.0.0.1:8768/` 打开。
- 服务只监听本机；每秒检测盘管模块的 HTML、CSS、JS 和数据库脚本，变化后自动刷新页面。
- 页面左下角显示“热更新已连接”才表示自动刷新生效。关闭命令窗口即可停止服务。

在项目根目录执行：`node src/02-盘管选型/tests/coil-selector.test.js` 和 `node src/02-盘管选型/tests/coil-data-io.test.js`。
源数据对照测试读取 `references/箱体设计规范/QHB-J02.577-2026A-规范文本提取.txt`；模块在浏览器中无需服务器或网络即可使用。

## 整机工作台专业选型回传

工作台通过同源 `/src/02-盘管选型/index.html` 打开本模块，预填箱体规格、推荐管径和排数，并传入稳定项目/机组/功能段 ID 与工作台输入指纹。工程师仍须确认 25W 系列、吊顶/落地安装形式、排数、管径和汇管径；非 25W、标准表无记录、管径冲突或规范尺寸冲突均不能应用正式型号。仅点击“应用到工作台”回传。

回传记录包括规则 ID/版本、当前数据库内容指纹、完整盘管输入快照、几何参考输出及性能边界警告。工作台按目标 ID、当前机组输入和标准规格再次复核，通过后写入七段式接口的 L2 `calculation / selection / output / validation` 字段；性能计算仍须使用规范指定的盘管计算软件。`file://` 不支持此同源回传流程。
# 2026-10 截面系列边界

`listFaceSectionCandidates` 支持 `series: 25W|50W`。候选源仍为 WK 盘管几何/有效面积数据；25W 外形尺寸按 `模数×100+50mm`，50W 按 `模数×100+100mm` 计算。该公式只生成箱体外形参考，不代表 50W 候选已完成制造或盘管适配验证。
