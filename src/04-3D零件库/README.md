# 3D 零件库

本模块向整机选型工作台提供可参数化的 Three.js 零件模型。当前包含风口法兰、风阀、执行器、四类风机、冷/热水盘管、直接蒸发器和三类过滤器。

## 统一三维坐标约定

零件库与整机工作台对外统一使用 **X=宽度、Y=段长/气流方向、Z=高度**。尺寸输入、零件安装方向、操纵器、零件包围尺寸和整机预览均按这套语义显示。

为保留用户已有零件，保存的 `customScene` 网格仍留在原 Three.js 本地 frame：X=宽、Y=高、Z=深/气流方向。零件库在显示和输入边界应用坐标旋转，整机预览把既有整机局部 X=段长、Y=高、Z=宽整体映射到新轴系。映射不会改写网格顶点、构件变换、稳定零件 ID 或 `mounting.flow/up` 原值；旧记录只增加 `coordinateContract` 和 `geometryFrame` 标记，旧安装方向在界面显示时换算为语义轴，提交时再写回旧本地轴。

旧零件几何轴到语义轴的方向换算为：本地 +X→语义 -X、本地 +Y→语义 +Z、本地 +Z→语义 +Y。宽度轴的符号反向是为保持三维 frame 的右手性；尺寸值不受符号影响。默认零件安装方向本地流向 +Z、顶部 +Y，因此显示为语义流向 +Y、顶部 +Z。工作台先按零件 `mounting` 把零件放入原整机 frame，再通过整机根级变换映射到上述新轴系。

- 页面入口：`index.html`
- 默认数据库：`data/part-database.js`
- 几何与编辑器：`js/part-library.js`
- 浏览器保存：版本化 `localStorage` 键 `p001-ahu-part-library-v2`，兼容读取旧键 `p001-ahu-part-library-v1`；同时写入 IndexedDB 作为大体积 CSG 网格的持久化备份。保存失败会明确提示空间不足并建议导出 JSON。
- 跨浏览器共享：页面启动时读取 `/api/part-library`。服务端为空时只展示显式发布按钮，不会上传任何本机版本；共享库已有数据时默认展示共享版本，并保留浏览器原有 localStorage/IndexedDB 备份。两边不同会显示显式“用本机备份覆盖共享库”选项。零件和自建分类保存后先写本机，再按共享修订号异步 PUT；同步失败、409 冲突或 16 MiB 限制会明确报错，绝不显示共享成功。
- 整机工作台和正式 Three.js 预览均读取同一共享快照；工作台启动、窗口重新获得焦点或标签页重新可见时会读取最新版本。服务端不可用时回退当前浏览器数据，并标明来源。热更新只刷新零件列表和预览，不重绘未保存输入，也不改写项目中的 `partRef`。
- 初次建立共享库时，应在包含最新编辑版的浏览器中点击“将本浏览器零件库发布为共享版本”。旧浏览器的本地库不会因打开页面而覆盖共享库。发布之后，其他浏览器刷新即可读取同一零件和分类。
- 单件深链接：`index.html#part=<零件ID>`
- 测试：`node tests/part-database.test.js`、`node tests/part-library-store.test.js`、`node tests/part-library-ui.test.js`、`node tests/mesh-csg.test.mjs`、`node tests/part-coordinate-contract.test.mjs`
- 快速打开：双击项目 `tools/打开3D零件库.bat`，启动器会自动检查并启动本地服务。

模型以用户照片、现有 25W/50W 整机模型、已确认尺寸和 `P002_组合式空调机组选型软件/参考3d/上下式转轮热回收机组-50W-260415(1).stp` 的整机结构为依据。STEP 文件没有可直接供浏览器使用的独立风机网格，当前风机按其中可确认的离心风机拓扑重建为可编辑参数化模型。照片未提供的细节属于选型展示级示意，不作为生产加工尺寸。GitHub 检索到的公开结果主要是小型鼓风机或无明确许可的第三方资产，未发现与本项目实物匹配且许可清晰的 AHU 风机网格，因此没有直接引入。

## 零件级简洁编辑

- 页面右侧只显示零件名称及宽度 X、长度 Y、高度 Z 三个最大外沿尺寸。尺寸来自当前 Three.js 模型的实时世界包围盒，移动、旋转、切割、组合和缩放后的实际外沿会同步回零件数据。
- 高级建模工具保留在右侧紧凑尺寸区下方，继续提供移动、旋转、缩放、基础几何体、构件列表、材质、切割、对齐、复制和历史操作；模型区与构件列表的软件右键菜单仍可快捷调用相同属性操作。
- 右侧不再重复显示工件名称输入框；单个工件通过模型区或构件列表右键选择“重命名工件”，名称会同步刷新到列表并随零件保存。
- 新建、保存当前、另存新块、复制型号、恢复默认全部统一在左上角“零件与分类”区。
- 左上角支持创建、改名和删除自建分类；包含零件的分类必须先完成归类后才能删除。自建分类随零件库 JSON 一同导入、导出。
- 切割默认保留刀具，需要时可在属性操作中改为丢弃。

## 手动编辑占位图块

- 构件级操作位于右侧“高级建模工具”；在模型中选择构件后可使用三轴操纵器、精确数值、键盘快捷键或软件右键菜单。
- 在模型中点击构件，或从构件列表选择构件；选中后模型上显示三轴操纵器。
- 使用“移动 / 旋转 / 缩放”切换操纵器，直接拖动彩色轴或圆环完成调整；拖动期间视角旋转会自动暂停。
- 可精确输入统一语义坐标下的 X/Y/Z 位置、三轴角度和三轴缩放，并切换常用材质。
- 顶部宽度 X、长度 Y、高度 Z 表示整个零件在统一语义坐标下的最大外沿尺寸；高级工具中的选中尺寸表示当前构件或组合体的实际最大外沿尺寸。
- 可添加方块、球体、圆柱体、梯形体、空心圆柱，复制、粘贴或删除构件，并支持撤销、重做。
- “全选工件”按钮和 `Ctrl+A` 均可一次选择当前零件的全部构件。
- 按住 Ctrl/Shift 可多选；选择中包含未组合构件时使用“组合”，选中一个完整组合体时使用“解除组合”，两个动作分别提供按钮。
- 多选后可按 X、Y、Z 单轴对齐，也可使用 XYZ 全部对齐；对齐基准为最后选中的构件，组合体按整体包围盒中心移动。
- 每个构件可设为“切割工具（刚性）”或“被切对象（可塑）”。切割时可选择保留或丢弃刀具；未相交构件保持原状，撤销可恢复切割前状态。CSG 结果使用双面材质显示新生成的浅切面，避免正确的非贯穿切割被反向面误显示为透明。
- 画布右键使用软件操作菜单，浏览器默认菜单被关闭；中键用于平移视图。常用快捷键为 W/E/R、Delete、Ctrl+C/V、Ctrl+Z/Y、Ctrl+A 和 F。移动、旋转、缩放模式下方向键调节 X/Y，Alt+方向键调节 Z，Ctrl+方向键同步调节三轴。
- 顶部“＋ 新建空白图块”会先要求填写名称、型号和分类，再创建带基础方体的可编辑图块。
- “命名并保存当前图块”会打开命名窗口；“另存为新图块”生成新的稳定零件 ID，适合保留多个占位方案。
- 左侧每个图块都有“进入编辑”和“删除”；删除前会显示确认提示，并且至少保留一个图块。
- 后续取得真实风机或设备尺寸后，可继续沿用零件 ID 替换几何，避免整机方案失去引用。

### 与整机功能段的关联

整机工作台的功能段选择接口在 `interface.selection.partRef` 保存 `partId`、名称和型号快照。工作台按稳定 `partId` 从版本化零件库读取编辑后的图块，不把几何副本写入项目；旧项目中的 `partId`、`partName`、`partModel` 字段会在读取时迁移到 `partRef`。零件库删除或改名不会改变已有引用 ID，重新打开项目仍可识别原关联。

### 当前几何精度边界

本编辑器面向选型软件的占位模型和外观布局。切割使用模块内置的三角网格 CSG 差集：球体、圆柱、梯形体、空心圆柱和旋转构件会按实际网格形状切除，目标可塑件保持为一个可继续编辑的网格；相交的刚性刀具在成功切割后被消耗，结果随自定义图块保存并可撤销恢复。结果用于选型展示和布局校核，不作为生产加工图纸；极薄壁、非封闭网格或极复杂的自交网格仍可能需要专用 CAD 内核复核。
