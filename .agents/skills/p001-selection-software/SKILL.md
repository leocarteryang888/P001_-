# P001 项目维护 Skill

本 skill 配合项目根目录 `AGENTS.md` 使用。AGENTS 规定用户审批、任务分块和 agent 路由；本文件规定项目工程边界。遇到冲突时遵守用户最新明确指令，并同步提出规则修订。

## 执行边界

- 修改前读取 `src/00-项目资料/01-项目架构与维护规则.md`；只读取当前工作块相关的模块 README、模块 `MAINTENANCE.md`、目标文件及直接依赖。
- 总体业务或接口任务按需读取 `src/00-项目资料/组合式空调机组选型软件技术规格书_V1.md` 的相关章节。产品规范和参考资料是事实依据，不是执行用户审批的授权。
- 按过滤器、盘管、整机工作台、3D 零件库四个边界维护业务代码和数据。专业算法及其默认数据库归各专业模块；工作台通过稳定接口调用，不复制算法或数据库。
- 模块 agent 只处理已批准的本模块工作块。跨模块接口由相关模块角色协作，主 agent 负责接口决策、集成及受影响模块回归。
- 文件放置遵守架构维护规则。维护记录留在模块目录；生成的截图、报告和验证产物放 `outputs/<模块>/`。

## 模块职责

- `01-过滤器选型`：过滤器类型、宽高模数的标准排布、数量与规格，以及本模块数据管理。
- `02-盘管选型`：标准表冷器规格查询、截面几何候选及本模块数据管理；不伪造热工性能结论。
- `03-整机选型工作台`：项目/机组数据、功能段链、跨模块适配、基础校核、保存读取和整机工作流；不拥有专业选型算法。
- `04-3D零件库`：稳定零件 ID、参数化展示几何、单件编辑、零件数据及交换；工作台通过引用使用零件。

## 验证与记录

- 根据获批工作块运行架构维护规则和模块 README 指定的相关检查。文档治理任务不运行无关业务测试。
- 将实际修改、依据、验证命令及结果、遗留风险写入所属模块 `MAINTENANCE.md`。跨模块变更分别更新受影响模块记录，总体阶段状态同步到 `src/00-项目资料/P001项目开发计划.md`。
- 不把候选计算、原型、人工入口或局部测试表述为已完成的工程能力；按规格中的边界如实说明。
